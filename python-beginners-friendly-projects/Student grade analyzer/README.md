# Student Grade Analyzer 📊

A simple Python tool to analyze student grades, calculate averages, and identify top and bottom performers.

## Features

- ✅ Calculates the average grade for each student
- ✅ Identifies the best and worst students
- ✅ Validates input data
- ✅ Uses type hints for better code clarity

## Requirements

- Python 3.10+

## How to Run

```bash
python student_analyzer.py
```
