# Guess the number

A simple number guessing game built with Python.
بازی حدس عدد — یک بازی ساده با پایتون

## How to run / نحوه اجرا

### 1. Install requirements / نصب پیش نیازها

pip install -r requirements.txt

### 2. Run the game / اجرای بازی

python Guessing_game.py

## How to Play / نحوه بازی

- A random number between **1 and 100** is chosen
- You have **5 chances** to guess it
- After each guess, you'll get a hint (bigger/smaller)
- Try to guess the number before you run out of chances!

- یک عدد تصادفی بین 1 تا 100 انتخاب میشه
- فقط 5 تا شانس داری که عدد رو درست حدس بزنی
- بعد از هر حدس، راهنمایی می‌گیری (بزرگتر/کوچکتر)
- سعی کن قبل از تموم شانس‌هات عدد رو پیدا کنی!

## Built With / ابزارها

- Python 3
- [Colorama](https://pypi.org/project/colorama/) — for colored terminal output / برای رنگ‌بندی متن در ترمینال
